Variant Hunter

Find hidden A/B test variants by taking repeated screenshots in independent Chromium sessions and comparing changed pixels.

This free proof of concept runs on GitHub Actions. Scans are launched from your GitHub account, not directly from this static page.

  1. Open the scanner workflow.
  2. Click Run workflow, enter a public HTTPS URL, choose the number of visits, and run it.
  3. When the run finishes, open it and download variant-hunter-report under Artifacts.
  4. Unzip the report and open index.html to compare screenshots and red difference masks.
